    Disclosed gap — rune rarity/slot-cost: the gamerguides.com rune database has no rarity column and no lens-slot-type column for individual runesnot available. The rarity and slot-type information shown above instead comes from each character's own rune-lens table, which states what a given slot accepts (e.g. "Rare Status") — not what any specific rune universally costs.

    Disclosed oddity — duplicate rune name: the Skill rune database lists "Rune of Skeleton King Flick" and "Rune of Summon Revenant Army" twice each, with different effect text per entry. Both source rows are kept as-is rather than silently merged or dropped.
